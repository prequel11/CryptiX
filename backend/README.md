# 🔐 CryptiX

An experimental cryptographic project focused on **entropy-driven key generation**, built using **Python, C, FastAPI, and SQLite**, with testing powered by **pytest**.

---

## 📖 Overview

CryptiX is a **hybrid-architecture entropy engine** that bridges low-level Windows kernel cryptographic primitives (via a C FFI) with a high-performance Python FastAPI backend to generate, store, and mathematically validate secure keys.

---

## 🎯 Objectives

* Study how entropy affects cryptographic strength
* Experiment with combining multiple randomness sources
* Build a structured pipeline for key generation
* Integrate APIs and storage into cryptographic workflows
* **Real-time Randomness Auditing:** Implements Shannon Entropy ( H(X) ) to mathematically evaluate the density and quality of generated byte pools

---

## ⚙️ System Approach

```id="gsih11"
Entropy Sources → Processing (C/Python) → Mixing → Key Generation → API (FastAPI) → Storage (SQLite)
```

## ▶️ How to Run

```bash id="run123"
# Clone the repository
git clone https://github.com/prequel11/CryptiX.git
cd CryptiX

# Compile the C engine into a shared library (DLL)
gcc -std=c17 -shared -o engine/flux_engine.dll engine/flux_engine.c -lbcrypt

# Run the FastAPI server
uvicorn main:app --reload
```
